读书清单

欢迎大家和我交流看过的书！“在读”和“想读”大部分也都读过~

显示已保存的清单。查看豆瓣主页

如首无作祟之物

[日] 三津田信三 / 张舟 / 文化发展出版社 / 力潮文创

2026-10-23 / ★★★★★ 力荐

对既有手法的创新演绎，将怪奇传说与杀人手法结合，带给人很好的氛围感，结尾的揭秘和多重反转让我很惊讶，体验非常棒。 完全没想到会是这样，即使线索早就铺垫过，即使手法“解释”过，太精彩了，才知道“本格”可以是这样的。

长日将尽

[英] 石黑一雄 / 冯涛 / 上海译文出版社

2026-08-24 / ★★★★★ 力荐

读到最后才发现是个悲伤的爱情故事，这种写作手法让我感到很特别和有趣。 说回剧情本身，以男主的第一视角来叙述，让我以为自己完全懂得男主的想法，却忘记自己也能够欺骗自己，隐瞒自己的感受，这种写法确实很有意思。有点像阿加莎的《罗杰疑案》带给我的体验。 读完还是有点难过的，有情人不能忠诚眷属的故事。也有点像《窄门》，两个人不知道在坚持些什么……也有点让我想到《求婚大作战》中的话，相爱之人为什么那么容易让矜持等造成难以挽回的错过……sad。 男主的遭遇，将全部的人生压在一个自己看不清、无法选择方向的事业上，当被证明是件错误的事业时，该是多么的悲惨。所以，我不想把人生的意义都放在事业上，我想更的放在生活的幸福上，个人的理想上。

妹妹人生（上）

入間人間 / 呂郁青 / 台灣角川

2025-11-14 / ★★★★★ 力荐

文笔极佳，很沉重的一本书。亲情？爱情？个人独立性？为了情感，能舍弃其余的多少？

解忧杂货店

2025-11-10 / ★★★★★ 力荐

都忘记之前看时的感动了，希望能再看一遍

窄门

[法] 安德烈·纪德 / 顾琪静 译者 / 顾琪静 / 天津人民出版社 / 果麦文化

2025-11-06 / ★★★★☆ 推荐

相爱，无外界阻挠，却不能走到一起，理念上的分歧让我感到绝望。这是很美，却又痛苦的爱情。 作者文笔极佳，写了许多有些抽象却又能传达出思想情感的段落，还有一些“情话”真的浪漫，但结局还是让我难过。
